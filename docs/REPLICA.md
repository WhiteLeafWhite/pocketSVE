# PocketSVE 0.3：原版界面、语音与骰子动画

## 安装

安装 `dist/pocketSVE-v0.3.0-debug.apk`。最低 Android 6.0，包名 `io.pocketsve.app`，可覆盖安装上一版 PocketSVE。应用不需要登录，也没有网络权限。

0.1 是功能原型；0.2 按原 APK 的对战组件和准备页重做布局；0.3 加入原始角色语音、操作音效和原版骰子动画。还原范围是主战者准备、对战显示和 NFC 读取界面，并非原应用全部页面。

## 本版操作

- 启动进入原版结构的准备页：对手在上、自己在下，七职业按 4+3 排列；选择后点击「开始」。
- 自己面板的「读取卡牌」打开原版图文 NFC 引导。成功读取后更新主战者；没有 NFC 或 NFC 关闭时显示设备状态。
- 对战页上方是对手生命，下方是自己生命；两侧加减，每次改变 1，范围 0–999。
- 左侧十格竖条表示 PP 上限，顶端加号、底端减号调整上限；已启用的球可设置可用 PP，重复点当前值会减 1。
- 下方 PP 数字上下的绿色箭头调整可用 PP。
- 绿色「回合开始」增加 PP 上限并回复 PP，具有原版 500ms 节流；右下蓝色「结束」为独立按钮，不扣除 PP。
- 圆形重置按钮直接将双方生命恢复 20、PP 恢复 0。菜单内另保留操作记录、撤销、主战者收藏等扩展功能。
- 表情数量与台词按主战者原表恢复，为 3、5 或 7 项。缺失文本保持为空，不伪配其他角色台词。
- 准备页「开始」播放登场语音，回合开始/结束和表情播放对应角色语音，读卡成功后播放对应读卡语音。资源全部内置，可离线播放。
- 骰子按钮播放原版六种点数各自的翻滚动画，再显示原版确认光效和 OK 图。翻滚期间不能重复掷骰，确认后关闭；不会修改 HP 或 PP。
- 菜单 → 对战设置 →「语音与音效」可关闭声音，设置保存在本机，与触觉反馈分别控制。关闭声音、进入后台时停止播放；回到前台不会自行续播。
- 本版主屏移除了原型中的 EP 区、生命栏名称、底部变更按钮和顶部 NFC 快捷入口，原对战组件树没有这些元素。

主战者收藏保留 82 条卡片记录，可通过菜单查看。NDEF Text `pocketsve:leader/100001`、JSON `{"cardId":"100001"}` 及本机 UID 绑定属于本项目扩展，原版 UI 主流程仍使用准备页读卡。所有 NFC 操作只读取标签。

## 还原依据与边界

已恢复原始职业图标、上下角色面板、生命数字两套纹理、竖 PP 底板、开始/结束/掷骰/表情按钮及按压贴图、原背景、33 张横向主战者缩略图和原字体。

原版布局主函数是 Hermes #22654，准备页 #22162，NFC 弹窗 #22647。尺寸和屏比公式逐项记录于 `analysis/original/battle-layout.json`、`battle-layout-findings.md`、`selection-layout-findings.md`。开始/结束台词与表情序列映射来自 #13100 及原始 CSV，见 `leader-lines-findings.md`。

目录有 82 条原卡记录，47 条有配套立绘，另 35 条在已取得的版本清单中没有对应立绘；收藏中明确标注。素材以本地 WebP 派生图打包，不依赖原服务器。

语音资源包含 651 个原始 WAV/MP3 文件，约 96.8 MiB，未转码。合并 APK 对应清单与原版运行时下载清单后，覆盖 65 名角色的登场/回合语音、64 名角色的读卡语音和 413 项表情语音；17 名角色缺失的音频保留为空，不替换为其他角色。具体来源与事件映射见 `analysis/original/leader-audio-findings.md`。本版角色语音使用单轨，切换台词会停止上一句；骰子滚动音效使用独立音轨叠加。

骰子复用了原版 `mdDice1` 至 `mdDice6` 和 `cmnUiDice1` 七套 Lottie 数据，使用内置 Lottie Web 播放，详见 `analysis/original/dice-layout-findings.md`。动画完成后延迟 500ms 显示确认效果，再延迟 300ms 允许关闭。

本版仍是独立重建：原版 React Native 与本版 Android WebView 的字体栅格化、动画合成可能不同；除骰子外的其他完整 Lottie 特效尚未移植。普通手机竖屏按原尺寸公式实现，平板等宽屏分支仍有近似。原版需要登录，未登录的原 APK 运行不能证明对战页逐像素一致，不能把静态尺寸核对称为完整一比一验收。

## 验证

- Node 核心测试：生命上下限、PP、状态恢复、原卡及 NDEF 映射。
- Edge 实际媒体播放测试：开始/结束/表情音频能解码且播放时间前进，声音开关持久化，暂停停止声音；骰子完整播放并确认关闭，双方 HP/PP 不变。
- Edge 离线交互测试：上下准备页、职业选择、NFC 弹窗、HP 纹理、独立回合按钮与节流、PP 消耗、直接重置、成功/失败 NFC 桥事件、皮肤缩略图与持久化。
- Java 原卡协议合成向量：UID、密码鉴权、READ 拼接、三级 AES 与错误 UID 拒绝。此次修改未改变生产 NFC 解码器。
- Android SDK 编译、DEX、16KB ZIP 对齐、v1/v2/v3 调试签名验证。
- 0.3 Android 15 模拟器真实点击检查：回合开始/结束及表情音频的播放时间前进、解码无错误；静音设置在应用重启后保留；Home 退到后台后四条音轨停止，返回前台不续播；骰子连续点击只触发一轮，SVG 帧实际变化且确认后正常关闭，HP/PP/回合不变。记录位于 `analysis/verification/runtime-v3`，实际录屏为 `dist/pocketSVE-v0.3.0-dice-demo.mp4`。
- Android 15（API 35、x86_64）模拟器安装启动，准备页、双方职业选择、无 NFC 设备提示、HP 加减及独立开始/结束操作已验证。运行中读取的实际状态确认 HP 变为自己 21 / 对手 19，开始后 PP 为 1/1，结束后 PP 保持 1/1；截图和状态位于 `analysis/verification/runtime-v2`。

实体 NFC 卡仍需带 NFC 的 Android 手机验证。模拟事件测试不代表硬件扫描通过。构建命令及源码入口见 [BUILD_ANDROID.md](BUILD_ANDROID.md)。
