# 洛菈米亚的自制 NFC 卡

适用安装包：`dist/pocketSVE-v0.4.0-debug.apk`。此角色在本项目按用户要求归为「皇家护卫」，编号 `svgdb-2808`。背景使用用户提供的原图，脸部定位在屏幕横向 50%、纵向 64%；上方以同色渐变衔接，不修改人物面部。

## 写卡

准备一台带 NFC 的安卓手机和一张**空白、可写、未锁定的 NTAG213 / NTAG215 / NTAG216 标签或卡片**。NTAG213 即可，标签只保存编号，图片和语音已经打包在 APK 内。NXP 的规格为三者分别提供 144 / 504 / 888 字节用户区，并支持 NDEF。

1. 开启手机 NFC，安装并打开 **NFC Tools**。
2. 进入「写入 / Write」→「添加记录 / Add a record」→「文本 / Text」。不同语言版本名称略有差异；选择标准文本记录，编码保持 UTF-8。
3. 只填入下面这一行，不加引号，也不填网页链接：

   ```text
   pocketsve:leader/svgdb-2808
   ```

4. 确认记录，返回写入页点击「写入 / Write」，把空白卡贴在手机 NFC 感应区，保持贴合直到提示成功。
5. 切到 NFC Tools「读取 / Read」，再贴一次卡，确认文本内容与上面完全一致。保留可写状态即可，不需要设置密码、改变 UID 或点击永久锁定。

## 在 PocketSVE 中使用

1. 安装 0.4.0，可覆盖上一版。
2. 打开应用，在准备页点击「读取卡牌」。
3. 将写好的卡贴近手机，读取成功后应出现洛菈米亚的缩略图。
4. 点击「开始」进入对战，显示皇家护卫生命框和指定背景。

也可在「菜单 → 主战者收藏」搜索 `2808` 或 `洛菈米亚` 手动选择。读取时应用需要处于前台的读卡界面；本格式不会从锁屏或桌面自动打开应用。

要为其他已收录主战者写卡，把最后的 `svgdb-2808` 换成收藏页显示的编号。例如亚里莎为 `pocketsve:leader/100001`。卡中不保存图片、语音或账号信息，换手机后只需安装包含该角色的版本，无需绑定 UID。

完整的 83 项对应关系见 [主战者 NFC 对照表](../dist/pocketSVE-v0.4.0-nfc-table.html)。可搜索名称或编号、按职业筛选、查看内嵌图片并复制完整写入文本。表中标明当前版本的图片与语音情况，未恢复名称的角色保留编号。建议每张自制卡只保留一条主战者文本记录，避免旧记录被优先识别。此表可用 `scripts/Export-NfcTable.mjs` 从当前目录重新生成。

这是 PocketSVE 的自定义文本卡格式，原官方应用不支持。实体手机与卡片尚未在本环境测试；已通过生产 Java 的 NDEF 分流测试及浏览器读卡事件到角色加载的集成测试。标准 PocketSVE Text/URI 标签不会发送原版 PWD_AUTH 指令；原版卡牌仍使用原来的校验流程。
